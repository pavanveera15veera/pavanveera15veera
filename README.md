### Selected work

**[FraudLens3D](https://github.com/pavanveera15veera/FraudLens3D)** — Geospatial risk scoring for NYC commercial zones
Joined 12 NYC Open Data sources (29K+ violations, inspections, 311 requests, fines) into one risk score per zone, surfacing operators whose combined exposure is invisible in any single dataset. Interactive 3D map built for insurance underwriting workflows: address search, chain-level ranking, portfolio aggregation.
`React` `Mapbox GL JS` `Python` `pandas`

**Maya** — AI agent for payroll regulatory change analysis *(industry-mentored)*
An agent detects new regulation versions by content hash and compares them. The LLM reads and explains; code verifies every quoted excerpt against the source, recomputes all money in exact decimal arithmetic, and routes anything failing one of eight conditions to a human reviewer. Immutable decision history, pytest suite validated against hand-computed expected values.
`Python` `Streamlit` `SQLite` `LLM agents`

**AutoDDG-Geo** — LLM-generated descriptions for geospatial datasets *(NYU Tandon)*
A deterministic profiler infers spatial role, geometry type and resolution across 1,000+ NYC Open Data datasets, then feeds that structured profile to an LLM. No hallucinated geometry. Geo-Faithfulness 0.5 → 1.0, retrieval metrics up ~3%.
`Python` `LLMs` `GeoPandas` `Shapely`

**Job Portal** — Full-stack recruitment platform *(published at NCCC'24)*
REST APIs for listings, applications and profiles over MongoDB. JWT auth with bcrypt hashing, file-validated resume upload, CORS.
`React` `Node.js` `Express` `MongoDB`
